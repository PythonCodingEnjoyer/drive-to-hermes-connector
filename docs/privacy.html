Политика конфиденциальности

Приложение: drive-to-hermes-connector
Редакция: 2026-11-02

Эта политика относится к личному подключению Google Drive, Docs и Sheets к локальному Hermes, которое использует владелец связанного репозитория. Этот сайт публикует описание подключения; он не принимает и не хранит файлы из Google Drive.

1. Доступные данные и назначение

После согласия пользователя подключение получает OAuth-разрешения для Google Drive, Google Docs и Google Sheets. Они могут давать доступ ко всем доступным аккаунту файлам, а не только к одному заранее выбранному документу.

Для порученных задач могут использоваться имена, идентификаторы, типы и другие метаданные файлов; содержимое нужных документов и таблиц; адрес авторизованного аккаунта для проверки подключения. Пользователь может поручить чтение, создание, обновление, удаление или изменение доступа к файлам. Gmail, Calendar и Contacts не входят в разрешения этой конфигурации.

2. Передача и использование ИИ

Запросы к файлам выполняются через Google API. Данные, нужные для конкретного задания, могут включаться в запрос к выбранной пользователем модели ИИ, включая GPT/Kimi, если такой провайдер настроен. Это не полностью офлайн-система.

Подключение не предоставляет владельцу этого сайта отдельную копию чужого Drive и не отправляет документы в GitHub Pages. Перед использованием внешней модели пользователь должен проверить её условия обработки, хранения и обучения на данных и выбрать настройки, совместимые с требованиями Google.

3. Ограниченное использование данных Google

Использование и передача данных, полученных из Google API, должны соответствовать Google API Services User Data Policy, включая требования Limited Use.

Данные используются для явно запрошенных пользователем функций. Политика подключения запрещает продажу данных Google, рекламное профилирование, оценку кредитоспособности и использование этих данных для разработки, улучшения или обучения обобщённых моделей ИИ/машинного обучения. Передача провайдеру ИИ допустима только для необходимой пользователю функции и на совместимых с этими ограничениями условиях.

Само подключение не контролирует внутренние системы внешних провайдеров. Эта политика не заменяет проверку их условий и настроек и не утверждает, что любой произвольно выбранный провайдер автоматически соответствует требованиям.

4. Локальное хранение

OAuth-конфигурация и токены сохраняются в профиле Hermes на компьютере пользователя. Они не включаются в публичный репозиторий сайта. Пользователь отвечает за безопасность компьютера, доступ к профилю и свои резервные копии.

Полученные данные могут сохраняться в локальных загрузках, истории разговоров, результатах выполнения задач и памяти Hermes в зависимости от настроек. Подключение не задаёт единого автоматического срока удаления этих копий. История и память требуют отдельного управления пользователем.

5. Отзыв доступа и удаление

Доступ можно отозвать в подключениях Google-аккаунта, выбрав соответствующее приложение. После отзыва новые обращения с этим разрешением должны прекратиться; локальные данные авторизации также можно удалить из профиля Hermes.

Отзыв доступа не удаляет уже сохранённые документы, историю чатов или данные у настроенного провайдера ИИ. Для их удаления нужны отдельные действия в соответствующих местах. Удаление исходного файла в Drive также не удаляет ранее созданные локальные копии.

6. Этот сайт и GitHub Pages

Сайт состоит из статических HTML/CSS-страниц. На нём нет собственных форм, аналитических скриптов, рекламных трекеров или механизма загрузки Google-файлов. GitHub как хостинг может обрабатывать технические сведения о посещении, например IP-адрес и параметры запроса, по своей политике конфиденциальности.

7. Связь и обновления

Вопросы о подключении и политике: Issues репозитория. Это публичный канал — не размещайте в нём секреты, файлы Drive и личную переписку. Изменения политики публикуются на этой странице с датой редакции; существенное изменение использования данных требует отдельного информирования пользователя.

English summary. This is a personal, local Google Drive/Docs/Sheets integration with Hermes. Task-relevant Google data may be sent to the user's configured AI provider. OAuth credentials stay in the local Hermes profile, not this public website. Google API data use and transfer must comply with the Google API Services User Data Policy, including Limited Use. Google data must not be used to train generalized AI/ML models.
