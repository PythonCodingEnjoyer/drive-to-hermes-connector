Google Drive в рабочем процессе Hermes

drive-to-hermes-connector — личное подключение владельца репозитория. Оно позволяет локальному Hermes работать с Google Drive, Google Docs и Google Sheets после разрешения пользователя.

Для чего нужен доступ

Пользователь может поручить Hermes найти файл, прочитать документ или таблицу, подготовить новый документ и сохранить результат на своём диске. Подключение использует официальные Google API от имени авторизованного пользователя.

  • Drive: поиск, чтение и операции с файлами по заданию пользователя.
  • Docs: чтение, создание и редактирование документов.
  • Sheets: чтение, создание и редактирование таблиц.

Разрешения могут охватывать весь доступный аккаунту Drive. Изменение, удаление и предоставление доступа к файлам требуют указания пользователя. Для этой конфигурации доступ к Gmail и календарю не запрашивается.

Это справочный сайт, а не онлайн-хранилище. На нём нет формы входа в Google. Авторизация и запуск подключения происходят в локальном приложении; документы, OAuth JSON и токены не публикуются здесь.

Где обрабатываются данные

OAuth-данные хранятся на компьютере пользователя. Если для выполнения задания нужна модель ИИ, относящиеся к задаче данные могут передаваться настроенному пользователем провайдеру — например, GPT/Kimi. Локальное хранение авторизации не означает полностью офлайн-обработку.

Подробности о передаче, локальной истории, сроках хранения и отзыве доступа приведены в политике конфиденциальности.

Связь

Технические вопросы можно оставить в Issues репозитория. Обращения публичны: не прикладывайте документы, пароли, токены и другие личные данные.
