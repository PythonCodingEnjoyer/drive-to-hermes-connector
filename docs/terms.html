Назначение

Подключение предназначено для личной работы владельца репозитория с разрешёнными ему данными Google Drive, Google Docs и Google Sheets через локальное приложение Hermes. Этот сайт является справочной страницей, а не публичным сервисом хранения, обработки или авторизации Google-аккаунтов.

Разрешённое использование

Используйте подключение только с аккаунтами и данными, к которым у вас есть право доступа. Соблюдайте условия Google, GitHub, Hermes и выбранного провайдера ИИ, а также применимые правила вашей организации. Наличие технического OAuth-разрешения само по себе не разрешает раскрывать чужие или служебные данные.

Проверка действий

Пользователь задаёт задачи и контролирует операции с файлами. Перед изменением, удалением, отправкой или предоставлением доступа проверяйте выбранные файлы и результат действия. Ответы ИИ могут содержать ошибки; важные сведения следует проверять по первоисточникам, а значимые файлы — резервировать.

Конфиденциальность и внешние модели

Работа с данными описана в политике конфиденциальности. Если задача использует внешнюю модель, относящиеся к ней данные могут передаваться выбранному провайдеру. Для данных Google необходимо использовать только условия и настройки, совместимые с Google API Services User Data Policy, включая Limited Use; нельзя передавать их для обучения обобщённых моделей ИИ.

Доступность и ограничения

Подключение предоставляется как есть для личного использования. Постоянная доступность, отсутствие ошибок, точность результатов ИИ и бессрочное действие авторизации не гарантируются. Google и другие провайдеры могут менять API, квоты, правила и сроки разрешений. Этот сайт не подтверждает прохождение официальной проверки Google.

Прекращение использования

Вы можете прекратить использование и отозвать разрешение в Google-аккаунте. Сохранённые локальные файлы, история Hermes и данные у внешних провайдеров удаляются отдельно в соответствии с их настройками.
